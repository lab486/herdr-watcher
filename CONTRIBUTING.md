# Contributing

Thanks for your interest in herdr-watcher.

**I'm not accepting pull requests yet.** Only collaborators can open them. I want to settle the design before I take outside code.

**Feature requests and bug reports are welcome.** Open an issue and pick a template.

- **Bug:** say what you did, what you expected, and what happened. Include your OS, your herdr version (`herdr --version`) and the herdr-watcher version.
- **A prompt shows no buttons, or the wrong ones:** this usually means Claude Code changed how a dialog looks. Attach the screen text from `herdr pane read <pane-id> --source visible --format text`, with anything private removed. These captures become test fixtures.
- **Feature request:** describe the problem you want solved, not only the feature.

To report a security problem, follow [SECURITY.md](SECURITY.md). Do not open a public issue for it.
